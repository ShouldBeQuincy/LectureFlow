# LectureFlow 3.3.1

[简体中文](#简体中文) · [English](#english)

## 简体中文

**Windows 下载哪个文件**：一般下载 `LectureFlow-Setup-3.3.1-x64.exe`（安装版，推荐）；不想安装的下载 `LectureFlow-3.3.1-x64-portable.exe`（便携版）。

3.3.1（2026-11-28）是 3.3.0 的修复版，只修一个问题：服务商使用 OpenAI 官方 API（`api.openai.com`）时，“测试连接”和用到这个服务商的各个角色（修复、翻译、摘要等）都会失败。其余内容与 3.3.0 相同，见 [3.3.0 发布说明](3.3.0.md)。

### 修复

- **OpenAI 官方 API 可以用了**：3.3.0 发往 `api.openai.com` 的请求用 `max_tokens` 表示输出上限，OpenAI 现在的模型不接受这个参数，请求被拒绝，报 HTTP 400（`Unsupported parameter: 'max_tokens' is not supported with this model. Use 'max_completion_tokens' instead.`）。现在发往 OpenAI 官方 API 的请求改用 `max_completion_tokens`。
- **只接受默认温度的模型**：有些模型（例如 OpenAI 的推理模型）只接受默认的 temperature，会拒绝 LectureFlow 各角色的固定温度。遇到 HTTP 400 指明 `temperature` 不受支持时，同一请求会不带温度再发一次；之后发给这个服务商的这个模型的请求都不再带温度（用模型自己的默认值），直到重启应用。
- **其他 OpenAI 兼容服务商**（DeepSeek、本地模型、各种代理与中转）照旧发送 `max_tokens`，请求与 3.3.0 完全一样。若某个服务商按 OpenAI 的错误格式回复“不支持 `max_tokens`”（或反过来不支持 `max_completion_tokens`），会改用另一个名字再发一次，并记住这个服务商与模型的选择，直到重启应用。
- 上面这些重发不等待，也不占用自动重试的次数，每种情况每次请求最多一次；任务卡片上的重试次数会把它算进去。其他 HTTP 400 仍然直接报错，不会重发。
- **从 DeepSeek 服务商改成 OpenAI 地址的服务商**：这样的服务商保留着“余额接口：DeepSeek（查询账户余额）”，3.3.0 发往 OpenAI 的请求因此带着 DeepSeek 专用的参数（`thinking` 等）。现在发往 OpenAI 官方 API 的请求一律不带这些参数；这类服务商的角色开了“深度思考”的，按关闭发送。

### 已知限制

- 只识别 OpenAI 格式的错误回复（`error.param` 与 `error.code`）。把错误改写成别的格式的代理不会触发重发；遇到这种情况，请查看它的说明，或改用 OpenAI 官方地址。
- 对 OpenAI 官方 API，以及改用 `max_completion_tokens` 的服务商，“测试连接”最多请求 16 个输出 token（其他服务商仍是 1 个），费用可以忽略。
- “测试连接”用第一个用到这个服务商的角色的模型；还没有角色用到它时，用模型列表按字母排序的第一个。OpenAI 的列表里排在最前面的可能不是对话模型，测试会因此失败。先在角色分配里给角色选好模型再测试即可。

### 升级

- 用应用内更新，或下载安装包覆盖安装即可。数据不变，不需要迁移。
- 浏览器扩展没有变化。

### 对应源码

每个版本的 Releases 附件里有安装包中 ffmpeg 与 aria2c 的对应源码（`LectureFlow-3.3.1-source-….tar`），按 GPL / LGPL 的要求与安装包在同一处提供。

## English

**Which file to download on Windows**: usually `LectureFlow-Setup-3.3.1-x64.exe` (the installer, recommended); `LectureFlow-3.3.1-x64-portable.exe` (the portable build) if you would rather not install.

3.3.1 (2026-11-28) is a fix release for 3.3.0 that fixes one problem: with a provider on OpenAI's own API (`api.openai.com`), "Test connection" and every role that used that provider (repair, translation, summary and so on) failed. Everything else is as in 3.3.0; see the [3.3.0 release notes](3.3.0.md).

### Fixes

- **OpenAI's own API works**: 3.3.0 sent the output limit to `api.openai.com` as `max_tokens`, which OpenAI's current models do not accept, so the request was refused with HTTP 400 (`Unsupported parameter: 'max_tokens' is not supported with this model. Use 'max_completion_tokens' instead.`). Requests to OpenAI's own API now use `max_completion_tokens`.
- **Models that take only the default temperature**: some models (OpenAI's reasoning models, for example) take only their default temperature and refuse the fixed temperature of LectureFlow's roles. When an HTTP 400 names `temperature` as not supported, the same request is sent once more without a temperature, and later requests to that model of that provider go without one (the model's own default applies) until the app restarts.
- **Other OpenAI-compatible providers** (DeepSeek, local models, proxies and relays) still get `max_tokens`, with requests exactly as in 3.3.0. If one answers in OpenAI's error format that `max_tokens` is not supported (or, the other way round, `max_completion_tokens`), the request is sent once more with the other name, and that choice is remembered for that provider and model until the app restarts.
- These resends do not wait and do not use up any of the automatic retries, and each happens at most once per request; the retry count on the job card does include it. Any other HTTP 400 is still reported at once and not sent again.
- **Providers changed from DeepSeek to OpenAI's address**: such a provider kept "Balance API: DeepSeek (check account balance)", so 3.3.0 sent DeepSeek's own parameters (`thinking` and others) to OpenAI. Requests to OpenAI's own API now never carry them; a role of such a provider with Thinking turned on is sent with it off.

### Known limits

- Only error answers in OpenAI's format (`error.param` and `error.code`) are recognised. A proxy that rewrites errors into another format does not trigger the resend; check its documentation, or use OpenAI's own address.
- "Test connection" against OpenAI's own API, and against a provider that switched to `max_completion_tokens`, asks for at most 16 output tokens (other providers still 1); the cost is negligible.
- "Test connection" uses the model of the first role that uses the provider; while no role uses it, the first model of its list in alphabetical order. The first models of OpenAI's list may not be chat models, and the test then fails. Choose a model for a role first, then test.

### Upgrading

- Update in the app, or install the new version over the old one. Your data is unchanged; there is nothing to migrate.
- The browser extension is unchanged.

### Corresponding source

Every release's assets include the corresponding sources of the ffmpeg and aria2c in the installers (`LectureFlow-3.3.1-source-….tar`), offered from the same place as the installers as the GPL and LGPL require.
