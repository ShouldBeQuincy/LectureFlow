# LectureFlow 3.3.0

[简体中文](#简体中文) · [English](#english)

## 简体中文

**Windows 下载哪个文件**：一般下载 `LectureFlow-Setup-3.3.0-x64.exe`（安装版，推荐）；不想安装的下载 `LectureFlow-3.3.0-x64-portable.exe`（便携版）。

3.3.0（2026-11-16）是 3.2.0 之后的一次大更新，重点是把已有的流程做稳、说清楚：会花钱的操作先问你；出了问题告诉你原因和下一步怎么办；工作台、讲座页、术语表和设置更顺手，键盘、读屏和手机宽度下的可用性改进很多；启动和大资料库下更快；更新、导入、录播下载和浏览器扩展做了一轮安全加固。升级前请先看“会影响你的变化”。

### 会影响你的变化

#### 安装与运行环境

- **建议安装在默认位置**（`%LOCALAPPDATA%\Programs\LectureFlow`），尤其是这台电脑还有别的账户时。装在别处时，安装程序要到解压完才把安装文件夹收紧为只有你能修改，应用内更新失败、回退之后这个权限也不会自动恢复；出现这些情况时诊断页会警告，并停用应用内更新。
- **从 3.2.0 升级到这一版的那次更新如果失败**：数据目录在默认位置时可以自动回退；数据目录不在默认位置的，请手动下载安装包重新安装。
- **网络代理**：LectureFlow 只按环境变量 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`（大小写均可）使用代理；访问 `https://` 地址只用 `HTTPS_PROXY`，不会退回 `HTTP_PROXY`；不读 Windows 的系统代理设置，一般也不用 `ALL_PROXY`。刮削录播只能用 `http://` 写法的代理，要经过 SOCKS 或 `https://` 写法的代理（包括这类 `ALL_PROXY`）时会拒绝并说明，不会悄悄直连。详见[安装说明](https://github.com/ShouldBeQuincy/LectureFlow/blob/v3.3.0/docs/install.md#网络代理)的“网络代理”一节。
- **网页模式或从源代码运行**：如果在 `config.toml` 里把 `python` 设成了系统 Python（包括微软商店版）并用 `pip install --user` 装的依赖，这一版起会找不到这些包，请改用虚拟环境（venv）。LectureFlow 启动 Python 时会忽略 `PYTHONPATH`、`PYTHONHOME`、`VIRTUAL_ENV` 等环境变量和用户目录里的包。桌面版用组件自带的环境，不受影响。
- **桌面版的启动参数**只认 `--disable-gpu`、`--disable-gpu-compositing`（不带值）和 `--lang=语言代码`（如 `--lang=zh-TW`）；带了别的参数会弹出说明并拒绝启动，说明里按原样显示被拒的参数。
- **桌面版与 `ELECTRON_DISABLE_SANDBOX`**：设了这个系统环境变量（不论取什么值）时，会弹出说明并退出，不再像以前那样约半秒后无声闪退；取消这个变量、重新打开启动它的终端或程序即可。
- **数据目录的路径长度**：上限改为 165 个字符（156 起提示“接近上限”）；超过 186 个字符时处理进程启动不了，会单独提示。数据目录较长时，部分组件装不了（视组件约从 81–110 个字符起），诊断页“数据目录位置”一行会列出这台电脑要用、却装不了的组件。默认的数据目录不受影响。

#### 文件、数据目录与导入

- **桌面版“添加本机文件”**只认你在文件对话框里选过或拖进来的文件。以下情形要重新选择：重启应用后，队列里还没开始的项；选好文件后超过 12 小时、期间没有任何文件添加成功；向导里“上传 → 粘贴 → 再切回上传”。
- **桌面版数据目录的检查、迁移与导入**：所有路径（包括本机文件夹和映射盘 `Z:`）都要先在文件夹对话框里选过；选好后要在 10 分钟内开始，在确认框里取消后要重新选一次。
- **导入旧资料库**：文件路径指向数据目录之外的、结构被改过（多出表、列、视图或触发器）的、有只差大小写的 id 的库会被拒绝，并说明原因；把自己的资料库复制到别的文件夹或换电脑后再导入，照常可以。本机的“自动检查更新”“组件下载源”等设置保留当前的，不会被导入的库覆盖；超过 100 个字符的术语不导入。**请只导入你信任的资料库**：库里的提供商设置（地址与 API key）和 Colab 授权仍会一起带入，库里排队中的任务导入后会自动开始。

#### 更新与退出

- **几份 LectureFlow 共用一个数据目录时**（例如安装版和便携版），一份已经下载好、还没安装的更新会挡住另一份的更新，最多 14 天；提示里会写明是哪一份。
- **回退到上一个版本时**，会把当时的数据库复制留一份（`lectureflow.db.lf-before-rollback`，只留最近一份）。它里面有封装过的 API key：你之后在应用里删掉 key，这份留存里仍在。
- **解压出来直接运行的副本**（没有经过安装）不再自己更新，只提示到发布页下载。
- **关窗与退出**：有任务正在处理或排队（包括还没刮削完的录播）时，关窗会先问你；托盘菜单里的“退出”也会先问（除非你在关窗对话框里记住了“退出”），托盘的这个对话框不提供“记住”。如果你记住了“在后台继续”，以后只有排队中的任务时，关窗也直接进通知区。
- **macOS** 上的 Cmd+Q、程序坞和应用菜单里的“退出”还不会先问。

#### 花钱与计费

- **会花钱的入口都先确认**：讲座的“更新”、“启动全部草稿”、“启动所选”、“更新过期讲座”等，现在都先弹确认框，写明几节、重跑哪些阶段、会（重新）计费，以及这些阶段上次花了多少；取消不发任何请求。跨几门课启动草稿时，确认框写明是哪几门课；用引导或预设里的“零成本档”时，不再说“按用量计费”。
- 在术语表里加或改一条术语后点“更新”，仍会整节重新修复和翻译（确认框会写明代价）。
- **思考设为“关”时**，Opus 5、Sonnet 5、Haiku 5.5 现在会真正关闭思考（以前实际上仍在思考并计费）。`claude-opus-5-5`、Fable、Mythos 的思考关不掉：“关”档按最低强度运行，并留出 12000 的思考余量，避免被截断后重发；这几个型号的“低”档余量也是 12000。
- 不在内置名单里的新 Claude 型号，思考“关”档也多留 12000 的输出余量；输出上限较小的代理可能因此报错，这时可以给该角色填写 `max_tokens`。
- 流式响应的空闲超时默认值改为 90 秒。

#### 界面与提示

- **大小的写法**：文件与磁盘大小改用 1000 进位（kB / MB / GB）（上传空间不足、远程服务器和引导里的磁盘大小也一样）；内存和显存仍按 1024 进位。
- **会一直留着的提示**（例如每个录播下载失败各一条）现在按窗口的宽度和高度最多显示最新的 1–3 条（窗口越小越少；条数按最长的提示来定，不会挤满窗口）。更早的没有丢，关掉新的就会露出来；同样的失败再次出现时会排到最前。
- 讲座阶段卡片上的用时改叫“本次用时”：中途取消后续跑、重启后接着跑时，从这一次开始算，不是总用时。
- 设置里“用预设添加”只添加服务；要让角色改用新服务，需要另外确认，改时保留原来的温度、思考等参数。
- 术语的原词和译名最多 100 个字符；导出的 `bilingual.md` 里不再生成链接。
- 网页模式拒绝来自别的网站的 `/api/` 请求（包括 GET）。

#### 隐私说明

- 隐私说明补全了发给模型服务的内容（课程名称与代码、原始文件名、课程大纲与课件的全部文字等），也写明了用远程服务器转写时录音会上传到那台服务器。
- 几处说法改得更准确：引导页的标题改为“讲座文件保存在这台电脑上”（讲座文字会发给你配置的模型服务，用 Colab 或远程服务器转写时录音也会上传，正文一直写明）；远程服务器（实验功能）在上传没完成、连接中断等情况下留下的文件，在连接结束约 2 小时后到期，到期后在 LectureFlow 下次连接那台服务器时删除，一直不再连接就会留在服务器上；模型回答里没能使用的部分记在本机的 `logs/llm` 文件夹（较长的只留开头和结尾），删除讲座时不会一并删除，约 14 天后到期，在下次向模型服务发请求时删除；把 `config.toml` 里的 `log_level` 设为 `debug` 时，完整的请求与回答也记在那里，规则相同。

#### 录播下载

- 单个任务最多 64 GiB；剩余空间低于 2 GB 时停下并保留已下载的部分，腾出空间后重试会接着下（提示里写明这个任务已经占了多少）；文件扩展名只接受白名单里的；续传要从同一个网站发来。
- 带用户名和口令的地址会被拒绝。
- 下到的不是录音或录像、遇到 DRM、格式不支持、网站被拦等重试也没用的失败，只给“移除”，不再给“重试”。

### 新增与改进

#### 出了问题时

- 模型拒答或超出总时限时，主按钮是“换模型重试…”（课程级的步骤则指向设置里的角色分配）；讲座页与工作台上只写换模型这一种出路。
- 多节讲座一起失败时按原因分组，可以“全部重试”。超过 24 小时的失败不再从工作台消失：课程卡片和导航显示失败数，工作台写“还有 N 节更早失败”。
- 拔电后暂停、每日预算用完时，会说明怎样继续；“去设置”直接打开出错的那个提供商；转写进程失败时给出原因，而不只是退出码；“重翻此句”返回和原来一样的句子时会说明。
- 翻译暂停时，“重翻此句”“保存原文”“恢复”等给出的提示会一直留着，直到你关掉。
- Colab 连不上但仍在计费时，工作台显示警告，并带“立即关机”。
- 所有句子都被模型拒答时，按“模型拒答”报告并停止，不再白白自动重试；任务的错误信息与日志里不再带模型生成的原文。
- OpenAI 兼容服务返回“内容过滤”时按拒答处理；DeepSeek 的“资源不足”会自动重试。

#### 进度与花费

- 讲座页的用量与金额同时给出“各阶段最近一次”和“累计”；转写时显示剩余时间估计。
- 取消转写后再重试，会从检查点接着转写，界面会说明。
- 被关窗或取消打断、一个 token 都还没收到的请求，不再算一次尝试。
- Claude 模型默认每批翻译 10 句，翻译更快也更省。
- 设置页对官方 Anthropic 地址显示账户限额与并发建议（只建议，不自动修改）。

#### 课程、讲座与播放器

- 课程可以改名、补填课程代码。
- 转写页的搜索会隐藏不匹配的句子。
- 下载菜单里每种格式都有一句说明。
- 播放器的窗口标题和讲座页一样显示课程名称。
- 转写重跑后，下一次导出会自动重排过期的章节；录音音量过低时，讲座上会有提示。
- 很短的句子（不超过 3 个词）不再因为长度比被误判为译文有问题；课程术语表整理的回答被截断时会立即拆小重试，转写不必多等。
- 讲座需要更新的原因里，课件的文件名现在带上界面语言的引号（中文用「」，英文和印地语用“”，俄语用«»），和周围的文字分得开；俄语界面里，句中的原因和“需要更新”后面的阶段名不再以大写字母开头。

#### 术语表

- 加完一条术语后，表格会滚到新的那一行并高亮约 2 秒，输入框仍保持焦点；新行被搜索、筛选或收起的分组挡住时，提示里会说明。
- “刚添加”的高亮修了两处：加完之后的读取里没有这条术语时，它不会在很久以后突然被滚到并高亮；加术语时恰好有一次读取失败，也不会取消新术语的高亮。
- “操作”列固定在表格右边，窗口较窄或右侧资源栏展开时也看得到。
- 500 条术语时改一条不再卡顿。

#### 设置

- 新增“用预设添加”提供商：选一个费用方案，按步骤拿到 API key。
- 提供商编辑框改过之后，按 Esc 或点对话框外面会先问“放弃对提供商的修改？”。
- 窄屏下“角色分配”的温度输入框不再被“深度思考”下拉框压住；窄卡片里的按钮不再伸出卡片。
- 设置页与“换模型重试…”对话框对最大输出 token 的检查规则一致。

#### 工作台

- 工作台自动刷新时，页面不再往上跳，正在操作的控件留在原处；打开确认框再取消也一样。
- 窄屏上 Colab 横幅把“另外还有一个更早的运行时没能释放”那一段折起来，点开才显示。

#### 键盘与读屏

- 讲座行的阶段进度条只占一个 Tab 站，用方向键在各段之间移动。
- 多处焦点不再掉到页面空白处：向导和对话框关闭后、复制引用和启动草稿后、菜单被页面滚动关掉后、“最近完成”的行经菜单操作后、“启动全部草稿”之后（焦点交给窗口里看得到的元素）。
- 每张课程卡片的“⋯”按钮名称带课程代码；Colab 警告更新数字时只读变了的那一段；修改原文的编辑框会读出旁边的说明；设置 → 组件、设置 → Colab 的状态行不再随页面刷新重复播报。
- 引导页和设置 → Colab 的登录区里，登录失败的提示和等待中的状态不再随页面刷新被读屏重复播报；引导页里“无法开始”的提示也一样。
- 文字与背景的对比度按 4.5:1 逐组检查过（有三处已知例外）。

#### 窄屏（手机宽度）

- 播放器控制栏在 360 / 414 宽下放得下；讲座行、下载队列、术语表卡片、设置页等的排版修好了。
- 课程页周标题里的日期不在中间断开；360 宽下工作台“待审修改”和“最近完成”的标题不再被挤。

#### 更快

- 启动到可用：在一个 400 节讲座的测试资料库上，从约 1.5 秒降到约 0.4 秒；设置、课程列表和工作台的数据加载更快。
- 播放器里有 1500 句时改一句、课程页里一节讲座有变化时，只重画变化的那一行。
- 大纲预览遇到异常输入不再卡住。

#### 转写与显卡

- 小显存显卡（4 GB、6 GB）改为按模型与精度估算显存，应当可以用 GPU 转写（没有在小显卡上实测，见“已知问题”）。
- 显存不够、而且推荐的模型还没装时，诊断页会明说。

#### Colab

- 令牌刷新遇到暂时性失败会原地重试；断线重连时换用新令牌；取消后最多等约 5 秒，释放在后台继续。
- Colab 返回的结果和远程服务器一样，经过严格检查后才保存。

#### 诊断

- 诊断页顶部有“导出诊断信息”。诊断包脱敏更彻底：不带 API key 的任何片段、用户名、主机名和完整的账户 SID。
- 提供商的地址是发往别的电脑的明文 `http` 时，诊断页会提醒 API key 和讲座内容会不加密地经过网络。
- 数据目录是目录联接时，诊断页如实检查它指向的目录；安装目录或数据目录别的账户也能修改时会警告；数据目录在磁盘或网络共享的根目录时有单独的提示。
- 诊断页“数据目录位置”一行在数据库繁忙时不再拖住页面：读取设置最多等约 1 秒，读不到时只按一定会用到的 Python 组件判断，并在下一次检查时重读，不会误列这台电脑用不到的转写组件。

#### 安全加固

- 导入被人改过的资料库后再删除课件，可能删到数据目录之外的文件夹——已修复：导入时严格检查，按 id 处理文件之前都会核对路径。
- 录播下载经过 LectureFlow 自己的本机代理，被重定向到本机或局域网地址时会拒绝。
- 组件下载会核对实际连上的地址有没有被重定向到别处；自定义的组件下载源只接受 `https`；组件安装只装预编译的包。
- 桌面版里打开外部链接有频率限制（10 秒内超过 3 个会被忽略，并有提示）。
- 显卡探测（nvidia-smi）和 Windows 上的硬件检测等子进程改在程序自己所在的文件夹里运行，不再沿用 LectureFlow 启动时的当前文件夹；当前文件夹里同名的程序不会被运行。
- 远程服务器（实验功能）的主机密钥变了时，必须核对旧指纹。

#### 其他

- 繁體中文、粵語、Русский、हिन्दी 的译文已随这一版补齐，新增的界面文字在这四种语言里都有译文；繁體中文把 lf-agent 的「代理程式」改叫「輔助程式」。
- 简体中文的错误框写“因此将关闭”（点“确定”后才退出）。
- 安装包里不再带 electron-updater。

### 修复

- 工作台自动刷新时，页面往上跳一截，正在操作的控件被推出窗口。
- 繁體中文里小于 1000 字节的文件大小显示成英文的“714 byte”。
- 有些提示里大小的单位重复（如“3.4 GB MB”）；组件安装因磁盘写满失败时显示“需要约 -1 MB”。
- 右侧资源栏展开时，课程页术语表的“操作”列看不见。
- 播放器控制栏在窄屏下超出屏幕。
- 关窗对话框对正在刮削的录播说法不对；托盘里的“退出”不提醒。
- 版本号只记在数据库日志文件里时，会误报“不是数据库”；现在正确提示“来自更新的版本”。
- 回退放回旧数据库时，如果日志文件删不掉，会留下“旧库 + 新版本日志”的组合。
- 诊断包里留着 API key 的末 4 位，以及“主机名\账户组”和完整的 SID。
- 改一句译文后，讲座页的金额只算最近这一次（现在另给累计）。

### 已知问题与没验证的

- 真实 GPU 上的整条流水线验收（转写、修复、翻译、导出，一节讲座）在发布当天进行，结果写在这一版 GitHub Release 页面的说明里；在那之前，这一版自 3.2.0 以来的修复依据的是自动化测试与代码审查。
- 数据目录放在 OneDrive、Dropbox 等同步文件夹里的情形没有实测（按代码判断可以用）。
- 没有在 macOS 上测试；Mac 上退出还不会先问。
- 没有用真实读屏软件（NVDA、讲述人）测试；读屏相关的改进只在代码和无界面浏览器里核对过。
- 浏览器扩展在 Firefox 上的端到端测试没能运行，Firefox 上的 Cookie 规则只在模拟环境里验证过；扩展的改动也没有在真实的学校录播页面上验证。
- 没有在真实 Colab 上验证令牌刷新、取消后的释放和结果检查；小显存显卡（4 GB、6 GB）没有实测，计算能力低于 7.0 的显卡（如 GTX 10 系）仍不能用 GPU 转写；真实的安装器、应用内更新与回退、有任务时的关窗对话框没有在真机上完整走过。
- 同一节讲座混用人民币和美元计价的提供商时，估算金额与每日预算会把两种币种直接相加。
- 课程目前不能删除。
- 应用重启后，被中断的阶段会显示“已重试 1 次”（重新排队用掉了一次自动重试）。
- 在提供商编辑框的“放弃修改？”上按 Esc 回到编辑框后，如果什么都不做又按 Esc，编辑框会直接关闭、不再询问（桌面版与 Chrome 类浏览器的限制）。
- 诊断页磁盘面板等少数地方的大小仍按 1024 进位，与别处差约 7%。
- 本机日志与诊断接口里仍有主机名和账户 SID（导出的诊断包里已替换）；把整个日志文件夹发给别人时请留意。
- 远程服务器转写仍是实验功能，默认关闭。

### 浏览器扩展

- **版本**：扩展 0.2.1（商店里上架的是 0.2.0）。新版本要重新通过 Chrome 网上应用店和 Firefox 附加组件站的审核，通过之前商店里仍是 0.2.0。Microsoft Edge 仍从 Chrome 网上应用店安装。扩展的权限没有变化。
- 打开弹窗时不再自动启动 LectureFlow：已安装但没打开时，弹窗给“打开 LectureFlow”按钮（你在弹窗里点“重新检测”时仍可能启动它）。
- 失败原因写成人话，重试也没用的失败不再出现“重试”；轨道在别的网站上时写“在 <主机> 上”；页面扫描超时时提示“页面还在加载”；弹窗最多列出 200 条轨道，其余写“还有 N 条轨道未显示”。
- 通用探测会读取页面标题：标题只发给本机的 LectureFlow，但会成为讲座的原始文件名，整理标题时还会发给你配置的模型服务。
- 屏蔽名单新增 `youtubeeducation.com`。
- **Cookie**：你点“发送”时，扩展要把视频网站的登录 Cookie 交给本机的 LectureFlow，应用才能下载。现在扩展只交浏览器在这个标签页里自己会带给那个网站的 Cookie，对策文件没有列出的网站不再交出全部 Cookie；同一所学校的不同子域名（例如 `lms.学校` 与 `media.学校`）、嵌入播放器所用的 CDN 等常见情形，按浏览器的同站规则交出需要的 Cookie。在 Firefox 里，嵌在别的网站页面中的播放器只交它在这个页面里的那一份（分区）Cookie，与 Firefox 自己的做法一致。又收紧了两处：浏览器自己也不会带登录 Cookie 的嵌套情形（例如学校的播放器被嵌在别的网站的框架里），扩展也不交；在 Chrome 132 及以上，个别情形下还会用浏览器自己算出的“顶层站点”再核对一次。这两处只会让扩展少交 Cookie，不会多交。如果某个以前下载得了的讲座现在发送后下载失败（应用报 401 或 403），请先在页面上播放几秒再发送；仍然失败请告诉我们。
- 安全修复：请求记录与嵌入帧的身份核对更严，后台为每个标签页保存的数据有了上限。
- Panopto 的内置对策升到 1.1.2（中文音轨提示改为“文件最小，只转写用它就够”）；俄语界面里两处说明的用词改得更准确。扩展更新后，已经打开的录播页面要刷新一次。
- 已知限制：页面给出异常庞大的 DASH 清单时，扩展只识别其中前面的部分（极少数情况下弹窗里多出一条文件轨道，下载的内容不受影响）；清单地址超过 8192 个字符时跳过这个清单、没有提示，这样的清单也无法从扩展发送（少见）。
- 给对策文件作者：静态检查更严（宽量词段、空分支、一个分组里多个不取字符的分支），每条正则第一次匹配前会预热计时，后台每分钟有 3 秒的总额度；详见[添加录播系统](https://github.com/ShouldBeQuincy/LectureFlow/blob/v3.3.0/docs/extension/adding-a-platform.md)。

## English

**Which file to download on Windows**: most people want `LectureFlow-Setup-3.3.0-x64.exe` (the installer, recommended); to run without installing, take `LectureFlow-3.3.0-x64-portable.exe` (the portable build).

3.3.0 (16 November 2026) is a large update after 3.2.0. It makes what was already there steadier and clearer: anything that costs money asks first; when something fails, LectureFlow tells you why and what to do next; the dashboard, lecture page, glossary and settings are easier to use, with many keyboard, screen reader and phone-width improvements; start-up and large libraries are faster; updates, library import, recording downloads and the browser extension went through a round of security hardening. Please read "Changes that affect you" before you upgrade.

### Changes that affect you

#### Installation and environment

- **Install in the default location** (`%LOCALAPPDATA%\Programs\LectureFlow`), especially if other accounts use this computer. Elsewhere, the installer locks the folder down to you only after it has unpacked the files, and after a failed in-app update rolls back, that protection is not restored by itself; in these cases the diagnostics page warns you and in-app updates are turned off.
- **If the update from 3.2.0 to this version fails**: with the data folder in its default location, LectureFlow rolls back by itself; with the data folder elsewhere, please download the installer and reinstall by hand.
- **Network proxy**: LectureFlow uses a proxy only through the environment variables `HTTP_PROXY`, `HTTPS_PROXY` and `NO_PROXY` (upper or lower case). `https://` addresses use `HTTPS_PROXY` only and never fall back to `HTTP_PROXY`. The Windows system proxy setting is not read, and `ALL_PROXY` is generally not used. Fetching recordings works only through an `http://` proxy; when a recording would have to go through a SOCKS or `https://` proxy (including such an `ALL_PROXY`), the fetch is refused with an explanation rather than going direct. See "Network proxy" in [the installation guide](https://github.com/ShouldBeQuincy/LectureFlow/blob/v3.3.0/docs/install.md#network-proxy).
- **Web mode or running from source**: if `python` in `config.toml` points to a system Python (including the Microsoft Store one) with packages installed by `pip install --user`, those packages are no longer found from this version on; please use a virtual environment (venv). LectureFlow now starts Python ignoring `PYTHONPATH`, `PYTHONHOME`, `VIRTUAL_ENV` and similar variables, and the packages in your user folder. The desktop app uses the environment of its own components and is not affected.
- **Command-line options of the desktop app**: only `--disable-gpu`, `--disable-gpu-compositing` (without a value) and `--lang=<language code>` (for example `--lang=zh-TW`) are accepted. With any other option the app shows an explanation, quoting the refused option as written, and does not start.
- **The desktop app and `ELECTRON_DISABLE_SANDBOX`**: with this system environment variable set (to any value), the app now explains why and quits, instead of closing silently after about half a second. Remove the variable and reopen the terminal or program that starts LectureFlow.
- **Length of the data folder path**: the limit is now 165 characters (a "close to the limit" note from 156); beyond 186 characters the processing worker cannot start, which has a note of its own. With a long data folder, some components cannot be installed (from about 81 to 110 characters, depending on the component); the diagnostics page's "data folder location" row lists the components this computer needs that cannot be installed there. The default data folder is not affected.

#### Files, data folder and import

- **"Add local files" in the desktop app** accepts only files you picked in the file dialog or dragged in. You need to pick them again: for items in the queue that had not started when the app was restarted; more than 12 hours after picking, if no file was added in that time; and in the setup guide after "upload → paste → back to upload".
- **Checking, moving and importing a data folder in the desktop app**: every path (local folders and mapped drives such as `Z:` included) must first be picked in the folder dialog; start within 10 minutes of picking it, and pick it again after cancelling the confirmation.
- **Importing an older library**: a library with file paths outside its data folder, with a changed structure (extra tables, columns, views or triggers) or with ids that differ only in case is refused, with the reason. Your own library copied to another folder or another computer imports as before. This computer's own settings such as "check for updates automatically" and "component download source" are kept, not overwritten by the imported library; terms longer than 100 characters are not imported. **Import only libraries you trust**: the providers (addresses and API keys) and the Colab authorization in the library are still brought in, and lectures queued in it start by themselves after the import.

#### Updates and quitting

- **Several copies of LectureFlow sharing one data folder** (an installed and a portable copy, for example): an update one copy has downloaded but not installed holds back the other copy's update, for at most 14 days; the message says which copy.
- **Rolling back to the previous version** keeps a copy of the database as it was (`lectureflow.db.lf-before-rollback`, only the latest one). It holds the protected API keys: a key you delete in the app later is still in that copy.
- **A copy that was unpacked and run without installing** no longer updates itself; it points you to the releases page.
- **Closing the window and quitting**: with lectures being processed or queued (recordings still being fetched included), closing the window asks first; "Quit" in the tray menu asks too (unless you chose to remember "Quit" in the close dialog), and the tray's dialog has no "remember" option. If you chose to remember "Keep running", closing the window with only queued lectures also goes straight to the notification area.
- **On macOS**, Cmd+Q and "Quit" in the Dock or the app menu do not ask yet.

#### Money and billing

- **Everything that costs money asks first**: a lecture's "Update", "Start all drafts", "Start selected", "Update out-of-date lectures" and the like now open a confirmation that says how many lectures, which stages run (again), that they are billed (again) and what those stages cost last time; cancelling sends nothing. Starting drafts from several courses names the courses; with the "zero-cost plan" from the setup guide or a preset, it no longer says "billed by use".
- Adding or changing a term in the glossary and then choosing "Update" still corrects and translates the whole lecture again (the confirmation says what it costs).
- **Thinking set to "off"** now really turns thinking off for Opus 5, Sonnet 5 and Haiku 5.5 (before, they still thought, and were billed for it). `claude-opus-5-5`, Fable and Mythos cannot turn thinking off: "off" runs at the lowest effort with 12,000 tokens of room for thinking, so that answers are not cut off and sent again; "low" for these models has the same 12,000.
- New Claude models that are not on the built-in list also get 12,000 extra output tokens with thinking "off"; a proxy with a small output limit may reject this, in which case set `max_tokens` for that role.
- The default idle timeout of streamed answers is now 90 seconds.

#### Interface and notices

- **Sizes**: file and disk sizes are in units of 1000 (kB / MB / GB) (so are the disk space for uploads, the remote server and the setup guide); memory and video memory stay in units of 1024.
- **Notices that stay until closed** (one per failed recording download, for example) now show only the newest one to three, depending on the window's width and height (fewer in a smaller one; the number is set so that even the longest notices do not fill the window). Older ones are not lost: they come back as you close newer ones, and the same failure happening again moves to the top.
- The time on a lecture's stage card is now labelled "This run": after a cancel and resume, or a restart, it counts from this run's start; it is not a total.
- "Add from a preset" in Settings only adds the service; having the roles use it is a separate confirmation, which keeps each role's temperature, thinking and other settings.
- Terms and their translations are at most 100 characters; the exported `bilingual.md` no longer makes links.
- Web mode refuses `/api/` requests from other websites (GET included).

#### Privacy statement

- The privacy statement now lists everything sent to model services (course name and code, original file name, the full text of the syllabus and slides, and so on), and says that with a remote server the recording is uploaded to that server.
- Some wording is now more exact: the setup guide's heading is "Lecture files are kept on this computer" (lecture text goes to the model services you set up, and recordings are uploaded for Colab or a remote server, as the text has always said); files left on a remote server (experimental) after an unfinished upload, a dropped connection and the like expire about 2 hours after the connection ends, are deleted the next time LectureFlow connects to that server, and stay there if it never connects again; parts of model answers that could not be used are kept in the local `logs/llm` folder (only the beginning and end of a long one), are not deleted with the lecture, expire after about 14 days and are deleted the next time LectureFlow sends a request to a model service; with `log_level = "debug"` in `config.toml`, whole requests and answers are kept there too, under the same rules.

#### Recording downloads

- At most 64 GiB per task. With less than 2 GB of free space a download stops and keeps what it has; retry after freeing space and it carries on (the message says how much the task already takes). Only file extensions on an allow list are accepted; a resumed download must come from the same website.
- Addresses with a user name and password are refused.
- Failures that a retry cannot fix (not a recording, DRM, an unsupported format, a blocked website and the like) offer only "Remove", no longer "Retry".

### New and improved

#### When something fails

- When the model refuses or the total time limit is reached, the main button is "Retry with another model…" (for course-level steps it points to the role assignments in Settings). The lecture page and the dashboard give only that way out.
- Several lectures failing together are grouped by reason, with "Retry all". Failures older than 24 hours no longer vanish from the dashboard: course cards and the navigation show the number of failures, and the dashboard says "N more failed earlier".
- After a pause because the computer was unplugged, or when the daily budget is used up, LectureFlow says how to go on; "go to Settings" opens the provider that failed; a failed transcription worker says why, not only its exit code; "Translate again" that returns the same sentence says so.
- While a lecture's translation is held, what "Translate again", "Save the English sentence", "Restore" and the like tell you stays until you close it.
- When Colab cannot be reached but is still billing, the dashboard shows a warning with "Shut down now".
- When the model refuses every sentence, LectureFlow reports a refusal and stops instead of retrying for nothing; task errors and logs no longer contain text the model wrote.
- A "content filter" answer from an OpenAI-compatible service counts as a refusal; DeepSeek's "insufficient resources" is retried automatically.

#### Progress and cost

- The lecture page shows usage and cost both for each stage's latest run and in total; transcription shows an estimate of the time left.
- Retrying a cancelled transcription continues from its checkpoint, and the page says so.
- A request interrupted by closing the window or by a cancel before any token arrived no longer counts as an attempt.
- Claude models translate 10 sentences per request by default: faster and cheaper.
- For the official Anthropic address, Settings shows your account's limits and a suggested concurrency (a suggestion only; nothing is changed for you).

#### Courses, lectures and the player

- Courses can be renamed, and a missing course code can be added.
- Search on the transcript tab hides the sentences that do not match.
- Each format in the download menu has a line saying what it is.
- The player's window title names the course, as the lecture page's does.
- After transcription runs again, the next export rearranges out-of-date chapters by itself; a recording that is too quiet gets a note on the lecture.
- Very short sentences (three words or fewer) are no longer flagged for their length ratio; when the course glossary's answer is cut off, it is split and retried at once, so transcription does not wait longer.
- In the reasons a lecture needs updating, slide file names are now in the interface language's quotation marks (「」 in Chinese, “” in English and Hindi, «» in Russian), set apart from the words around them; in the Russian interface, a reason in mid-sentence and the stage names after "needs updating" no longer start with a capital letter.

#### Glossary

- After you add a term, the table scrolls to its row and highlights it for about 2 seconds, with the focus still in the input box; when the search, a filter or a collapsed group hides the new row, the message says so.
- Two fixes to the highlight of a term just added: when the read after adding does not list the term, it is no longer scrolled to and highlighted much later; and a read that happens to fail while the term is being added no longer takes the highlight away.
- The actions column stays at the right edge of the table, so it is visible in a narrow window or with the resources panel open.
- Changing one of 500 terms no longer makes the page stall.

#### Settings

- New: "Add from a preset" for providers: choose a cost plan and follow the steps to get an API key.
- After you change something in the provider dialog, Esc or a click outside it first asks "Discard changes to the provider?".
- In a narrow window, the temperature box of the role assignments is no longer covered by the thinking menu, and buttons in narrow cards stay inside the card.
- Settings and the "Retry with another model…" dialog check the maximum output tokens by the same rule.

#### Dashboard

- When the dashboard refreshes, the page no longer jumps up: the control you are using stays where it was, also after cancelling a confirmation.
- In a narrow window, the Colab banner folds away the sentence about an earlier runtime that was not released either; it opens on a click.

#### Keyboard and screen readers

- The stage bar of a lecture row is one Tab stop; the arrow keys move between its segments.
- The focus no longer falls to an empty part of the page in many places: after the setup guide or a dialog closes, after copying a citation or starting a draft, after a menu is closed by scrolling the page, after a menu action on a "recently finished" row, and after "Start all drafts" (the focus goes to something visible in the window).
- Each course card's "⋯" button includes the course code in its name; the Colab warning reads out only the part whose number changed; the English sentence's edit boxes read out the notes beside them; the status lines in Settings → Components and Settings → Colab are no longer read out again on every refresh.
- In the Colab sign-in on the setup guide and in Settings → Colab, the sign-in failure alert and the waiting status are no longer read out again on every refresh; nor is the setup guide's "could not start" alert.
- Text contrast is checked pair by pair against 4.5:1 (with three known exceptions).

#### Narrow windows (phone width)

- The player's controls fit at 360 and 414 pixels wide; the layout of lecture rows, the download queue, the glossary card, Settings and more is fixed.
- Dates in the course page's week headings no longer break in the middle; at 360 pixels the dashboard's "changes to review" and "recently finished" titles are no longer squeezed.

#### Faster

- Ready after start-up in about 0.4 seconds instead of about 1.5 seconds (measured on a test library of 400 lectures); Settings, the course list and the dashboard load faster.
- Changing one sentence of a 1,500-sentence lecture in the player, or a change to one lecture on a course page, redraws only that row.
- The syllabus preview no longer hangs on unusual input.

#### Transcription and GPUs

- GPUs with little memory (4 GB, 6 GB) now get a memory estimate by model and precision, and should be able to transcribe (not tested on such cards; see "Known issues").
- When video memory is short and the recommended model is not installed, the diagnostics page says so.

#### Colab

- A temporary failure while refreshing the token is retried on the spot; reconnecting uses a fresh token; a cancel returns within about 5 seconds and the release goes on in the background.
- Results from Colab are checked as strictly as those from a remote server before they are saved.

#### Diagnostics

- "Export diagnostics" is at the top of the diagnostics page. Diagnostic bundles are scrubbed more thoroughly: no part of an API key, no user name, no host name and no full account SID.
- When a provider's address is plain `http` to another computer, the diagnostics page warns that the API key and the lecture content cross the network unencrypted.
- When the data folder is a directory junction, diagnostics check the folder it points to; an installation or data folder that other accounts can change gets a warning; a data folder at the root of a drive or network share gets a note of its own.
- The diagnostics page's "data folder location" row no longer holds up the page while the database is busy: it waits about a second for the settings, and when they cannot be read it goes by the Python component alone, which is always needed, reads them again at the next check, and no longer lists transcription components this computer does not use.

#### Security hardening

- After importing a library someone had tampered with, deleting a slide file could delete a folder outside the data folder. Fixed: imports are checked strictly, and paths are checked before any file is handled by its id.
- Recording downloads go through LectureFlow's own local proxy and are refused when redirected to this computer or the local network.
- Component downloads check whether the address actually reached was redirected elsewhere; a custom component download source must use `https`; components are installed from pre-built packages only.
- Opening external links from the desktop app is rate-limited (beyond 3 within 10 seconds they are ignored, with a notice).
- Child processes such as GPU detection (nvidia-smi) and the hardware detection on Windows now run in their own program's folder instead of the folder LectureFlow was started from; a program of the same name in that folder is never run.
- When a remote server's (experimental) host key changes, the old fingerprint must be checked.

#### Other

- The Traditional Chinese, Cantonese, Russian and Hindi translations are complete for this version: new interface texts have translations in all four. Traditional Chinese now calls lf-agent 「輔助程式」 instead of 「代理程式」.
- The Simplified Chinese error dialog says the app "will close" (it quits after you press OK).
- The installer no longer includes electron-updater.

### Fixes

- When the dashboard refreshed, the page jumped up and pushed the control in use out of the window.
- In Traditional Chinese, file sizes under 1000 bytes showed as the English "714 byte".
- Some messages repeated the unit of a size ("3.4 GB MB"); a component install that failed on a full disk said "about -1 MB is needed".
- With the resources panel open, the actions column of the course page's glossary was out of sight.
- The player's controls ran off the screen in a narrow window.
- The close dialog described recordings still being fetched wrongly; "Quit" in the tray did not ask.

- After one sentence was changed, the lecture page's cost counted only that latest run (a total is now shown as well).

### Known issues and what was not verified

- The end-to-end acceptance run on a real GPU (transcription, repair, translation and export of one lecture) takes place on the day of release, and its result is recorded in the notes on this version's GitHub Release page; until then the fixes since 3.2.0 rest on automated tests and code review.
- A data folder inside a OneDrive, Dropbox or similar synced folder was not tested (by the code, it should work).
- Not tested on macOS; on a Mac, quitting does not ask yet.
- Not tested with a real screen reader (NVDA, Narrator); the screen reader improvements were checked in the code and a headless browser only.
- The browser extension's end-to-end tests could not run on Firefox, and the cookie rules on Firefox were verified in a simulated browser only; the extension's changes were not tried on real university recording pages either.
- Not verified on real Colab: token refresh, the release after a cancel and the result checks. GPUs with 4 or 6 GB were not tested, and GPUs with a compute capability below 7.0 (such as the GTX 10 series) still cannot transcribe on the GPU. The real installer, in-app update and rollback, and the close dialog with lectures running were not walked through on a real machine.
- When one lecture uses providers priced in yuan and in US dollars, the estimated cost and the daily budget add the two currencies together.
- Courses cannot be deleted yet.
- After a restart, an interrupted stage shows "retried once" (queuing it again used up one automatic retry).
- In the provider dialog, after Esc on "Discard changes to the provider?" takes you back, pressing Esc again without doing anything else closes the dialog without asking (a limit of the desktop app and of Chrome-based browsers).
- A few places, such as the disk panel on the diagnostics page, still show sizes in units of 1024, about 7% off from the rest.
- Local logs and the diagnostics interface still contain the host name and account SID (exported diagnostic bundles replace them); mind this if you send someone the whole log folder.
- Transcription on a remote server is still experimental and off by default.

### Browser extension

- **Version**: extension 0.2.1 (the stores have 0.2.0). The new version has to pass review on the Chrome Web Store and Firefox Add-ons again; until then the stores keep 0.2.0. Microsoft Edge still installs it from the Chrome Web Store. The extension's permissions are unchanged.
- Opening the popup no longer starts LectureFlow by itself: when it is installed but not open, the popup offers "Open LectureFlow" ("Check again" in the popup may still start it).
- Failures are explained in plain words, and failures a retry cannot fix no longer offer "Retry"; a track on another website says "on <host>"; a scan that times out says the page is still loading; the popup lists at most 200 tracks and says how many more are not shown.
- Detection on general pages reads the page title. It goes only to LectureFlow on this computer, but becomes the lecture's original file name, and when titles are tidied it is sent to the model service you set up.
- `youtubeeducation.com` is added to the block list.
- **Cookies**: when you press "Send", the extension hands the video website's sign-in cookies to LectureFlow on this computer so that it can download. The extension now hands over only the cookies the browser itself would send that website from this tab; websites that no platform profile lists no longer give up all their cookies. Common cases such as different subdomains of the same university (`lms.<university>` and `media.<university>`, for example) or the CDN of an embedded player get the cookies they need by the browser's same-site rules. In Firefox, a player embedded in another website's page gets only its partitioned cookies for that page, as Firefox itself does. Two more tightenings: in nested pages where the browser itself would not send the sign-in cookies (a university player embedded inside another website's frame, for example), the extension does not hand them over either; and in Chrome 132 and later, in some cases, it also checks the "top-level site" the browser itself works out. Both only ever hand over fewer cookies, never more. If a lecture that used to download now fails after sending (LectureFlow reports 401 or 403), play the video for a few seconds and send it again; if it still fails, please tell us.
- Security fixes: stricter checks of request records and of embedded frames' identity; the data kept in the background for each tab has a limit.
- Panopto's built-in profile is now 1.1.2 (its Chinese audio-track hint reads better); two notes in the Russian interface use a more accurate word. After the extension updates, reload recording pages that were already open.
- Known limits: for a page with an extremely large DASH manifest, the extension recognises only its first part (in rare cases the popup shows one extra file track; what is downloaded is not affected); a manifest whose address is longer than 8,192 characters is skipped without a notice and cannot be sent from the extension (rare).
- For profile authors: the static checks are stricter (wide quantified segments, empty alternatives, several alternatives in one group that take no characters), every regular expression is warmed up and timed before its first match, and the background has a total of 3 seconds per minute; see [Adding a recording platform](https://github.com/ShouldBeQuincy/LectureFlow/blob/v3.3.0/docs/extension/adding-a-platform.md).
